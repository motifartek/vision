# Nasil eleyecegiz

Her aday icin tek soru: **bu videodan sartnamedeki gibi uc satirlik bir zaman
cizelgesi cikarabilir miyim?**

```
00:15 — Forklift devrildi
00:20 — Yerde hareketsiz kisi
00:35 — Personel toplandi
```

Cikaramiyorsan video uygun degil. Ek olarak:

- Kirpilmamis mi? Olayin oncesi ve sonrasi kadrajda mi?
- 30 sn - 3 dk arasi mi?
- Sabit kamera mi? (final testinde gozetim kamerasi bekleniyor)
- Tek surekli cekim mi, yoksa derleme mi?

Uygun bulduklarini bana soyle, ben indirip kataloga eklerim:

```
python Utilities/golden-dataset/add_video.py <dosya> --kaynak <url> --not "..."
```
